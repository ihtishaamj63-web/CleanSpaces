Setup
Clone the repo
Backend: cd backend → npm install → copy .env.example to .env and fill in your values → create the database and run schema.sql
Frontend: cd frontend → npm install
Run: backend npm run dev (port 5000), frontend npm run dev (port 5173)
Branches
main — stable version, protected
develop — integration branch, all pull requests go here
feature/* — personal working branches, created from develop
